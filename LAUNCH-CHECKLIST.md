# Before you share Sidequest

1. **Put your email on the privacy page.** Open `public/privacy.html`, search for `REPLACE_WITH_YOUR_EMAIL` (it appears twice on one line) and replace it with the address people should write to.
2. **Finish the credits page.** Open `public/credits.html`. The wing and face credits are already in. Find the `TODO` comment near the bottom and add the credits for the body, hair, clothing, shield and weapon art. Get them from the LPC character generator's credits download for the character you built.
3. Push to GitHub (`git add -A`, `git commit -m "Privacy, credits, install prompts"`, `git push`) and wait for Vercel to finish.
4. Check these links work on your live site: `/privacy.html` and `/credits.html`.
5. Then continue with the domain and email steps.
